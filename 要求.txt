1、实验目的
本实验旨在通过构建一个完整的“实验室预约与设备管理系统”，让学生深入理解并掌握前后端分离架构下的全栈开发流程。具体目标包括：
掌握 Vue 2组合式 API：熟练使用 vue相关语法及组件化开发。
理解状态管理与路由：使用 Pinia 进行全局状态管理，使用 Vue Router 实现页面跳转与权限控制。
精通后端 Servlet 分层架构：摆脱传统 JSP 模式，掌握基于原生 HttpServlet 的分层设计（Entity-DAO-Service-Servlet），理解 Filter 拦截器机制及统一响应格式的设计。
实践数据可视化与文件处理：集成 ECharts 展示统计数据，实现基于 Multipart 的文件上传功能。
培养工程化思维：通过 Axios 封装、CORS 跨域处理、Token 认证等机制，提升系统的安全性与可维护性。
2、实验内容
学生需独立或分组完成以下模块的开发与集成：
基础架构搭建：配置  Vue2 前端环境，配置 Tomcat 10 + Java 17 后端环境，建立 MySQL 数据库连接。
用户认证模块：实现注册、登录、角色区分（学生/教师/管理员），基于 Token 的身份验证及路由守卫。
资源管理模块：实现实验室和设备的 CRUD（增删改查），支持状态管理（空闲/占用/维修）。
核心业务模块：实现预约功能，包含时间段冲突检测、防超员逻辑、审核流程（通过/拒绝）。
辅助功能模块：
统计可视化：使用 ECharts 展示各实验室周使用率。
操作日志：记录关键操作（谁、何时、做了什么）。
文件上传：支持上传实验报告或设备图片。
3、实验知识点
前端技术：Vue 3 (Composition API), Vite, Vue Router 4, Pinia, Element Plus, Axios, ECharts。
后端技术：Java 17, Jakarta EE (Servlet 5.0/JSP 3.0 for Tomcat 10), JDBC, Druid 连接池, Jackson/Gson。
数据库：MySQL 8.0+，SQL 事务控制，索引优化。
核心概念：RESTful API 设计规范，MVC/MVVM 设计模式，CORS 跨域资源共享，JWT/Token 认证原理，文件流处理。

二、实验分析
6.1 系统架构设计
系统采用典型的前后端分离架构。
前端：负责页面渲染、用户交互、数据展示。通过 Axios 发送 HTTP 请求，接收 JSON 数据。
后端：作为 API 服务器，处理业务逻辑。
Filter 层：处理字符编码、CORS 跨域、Token 合法性校验。
Servlet 层：接收请求，调用 Service，返回 JSON。
Service 层：核心业务逻辑（如预约冲突检测、权限判断）。
DAO 层：直接操作数据库。
数据库：存储持久化数据。
6.2 数据库设计 (ER 简述)
user: id, username, password, role (student/teacher/admin), create_time
lab: id, name, capacity, status (available/maintenance), description
device: id, lab_id, name, model, status
reservation: id, user_id, lab_id, start_time, end_time, status (pending/approved/rejected), create_time
log: id, user_id, action, detail, create_time
6.3 关键技术难点
Tomcat 10 兼容性：必须使用 jakarta.servlet 包，否则类加载失败。
预约冲突检测：需确保同一实验室在同一时间段内，已批准的预约人数不超过容量，且时间不重叠。
跨域问题：前端端口（如 5173）与后端端口（如 8080）不同，需后端配置 CORS Filter。

package com.lab.dao;  import com.lab.entity.Lab; import com.lab.util.DbUtil; import java.sql.*; import java.util.ArrayList; import java.util.List;  public class LabDao {     public List findAll() throws SQLException {         List labs = new ArrayList<>();         String sql = "SELECT * FROM lab";         try (Connection conn = DbUtil.getConnection();              PreparedStatement ps = conn.prepareStatement(sql);              ResultSet rs = ps.executeQuery()) {             while (rs.next()) {                 Lab lab = new Lab();                 lab.setId(rs.getInt("id"));                 lab.setName(rs.getString("name"));                 lab.setCapacity(rs.getInt("capacity"));                 lab.setStatus(rs.getString("status"));                 labs.add(lab);             }         }         return labs;     } } 复制
2.3 Service 层示例 (ReserveService - 冲突检测)
package com.lab.service;  import com.lab.dao.ReservationDao; import com.lab.entity.Reservation; import java.sql.SQLException; import java.time.LocalDateTime;  public class ReserveService {     private ReservationDao dao = new ReservationDao();      /**      * 检查预约冲突      * 规则：同一实验室，时间重叠，且状态为 approved 或 pending      */     public boolean hasConflict(int labId, LocalDateTime start, LocalDateTime end) throws SQLException {         // SQL: SELECT count(*) FROM reservation          // WHERE lab_id = ? AND status IN ('approved', 'pending')          // AND start_time < ? AND end_time > ?         return dao.countConflicts(labId, start, end) > 0;     }          public boolean submitReservation(Reservation res) throws SQLException {         if (hasConflict(res.getLabId(), res.getStartTime(), res.getEndTime())) {             return false; // 冲突         }         return dao.insert(res) > 0;     } } 复制

2.5 Filter 配置 (CorsFilter & AuthFilter)
CorsFilter.java:
package com.lab.filter;  import jakarta.servlet.*; import jakarta.servlet.annotation.WebFilter; import jakarta.servlet.http.HttpServletResponse; import java.io.IOException;  @WebFilter("/*") public class CorsFilter implements Filter {     @Override     public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain) throws IOException, ServletException {         HttpServletResponse httpResp = (HttpServletResponse) resp;         httpResp.setHeader("Access-Control-Allow-Origin", "*");         httpResp.setHeader("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS");         httpResp.setHeader("Access-Control-Allow-Headers", "Content-Type, Authorization");                  if ("OPTIONS".equalsIgnoreCase(((HttpServletRequest) req).getMethod())) {             httpResp.setStatus(HttpServletResponse.SC_OK);             return;         }         chain.doFilter(req, resp);     } } 复制
